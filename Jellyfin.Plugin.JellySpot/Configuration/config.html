JellySpot

Admin settings: storage path, Spotify app credentials, and download limits. Users link Spotify under JellySpot Sync.

Storage

Folder where downloads are saved. Point a Jellyfin music library at this path.
Leave empty to use ffmpeg from PATH / Jellyfin.

Spotify app

Must match the Spotify Developer Dashboard. Example: http://127.0.0.1:8096/JellySpot/OAuth/Callback
